Microservice d'authentification et de gestion des utilisateurs (Node.js, Express).
Fait partie du projet Gestion Bibliothèque : voir le dépôt `gitops-config` pour l'architecture globale.

## Endpoints
- `GET /health` : état du service
- `POST /register` : création de compte (à venir)
- `POST /login` : connexion JWT (à venir)

## Lancement local
npm install
npm start

## Variables d'environnement
- `PORT` : port d'écoute (défaut 3000)# user-service
